# Aplikasi Portofolio Pribadi

Aplikasi portofolio pribadi berbasis Flutter untuk tugas praktikum Pemrograman Mobile.

## Fitur

- Header profil dengan foto dan informasi identitas
- Tab About Me berisi fakta pribadi dan keahlian
- Tab Portfolio berisi tiga proyek/karya
- Tab Contact berisi email dan tautan sosial media
- Halaman detail portfolio dengan `Navigator.push`
- Tema warna biru muda yang konsisten di seluruh aplikasi

## Fitur Pengembangan yang Dipakai

- A: Halaman detail portfolio baru
- C: Tema warna biru muda

## Asset

## Cara Menjalankan

```bash
flutter pub get
flutter run
```
